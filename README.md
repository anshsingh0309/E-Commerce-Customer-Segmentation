Customer Segmentation using RFM, K-Means and DBSCAN
Project Overview
This project performs customer segmentation on the Online Retail dataset from the UCI Machine Learning Repository. It uses RFM analysis and two unsupervised machine-learning algorithms, K-Means and DBSCAN, to group customers based on their purchasing behaviour.

The goal is to understand customer activity and spending patterns so that different customer groups can be identified.
Dataset
- Dataset: Online Retail
- Source: UCI Machine Learning Repository
- Dataset ID: 352
- Access method: ucimlrepo Python package
The notebook retrieves the dataset directly from UCI, so a separate manual download is not required when internet access is available.

Project Workflow
1. Import libraries and load data
The required Python libraries are imported, and the Online Retail dataset is fetched using ucimlrepo.
2. Data inspection and cleaning
The notebook:
- Checks the dataset structure and missing values.
- Removes rows without a CustomerID.
- Removes cancelled invoices (invoice numbers beginning with C).
- Keeps only records with positive quantity and unit price.
- Removes duplicate records.
- Converts customer IDs and invoice dates to suitable data types.
3. Feature engineering and RFM analysis
Revenue is calculated as:

Revenue = Quantity × UnitPrice

The data is grouped by customer to calculate:
- Recency: Number of days since the customer's most recent purchase.
- Frequency: Number of distinct invoices/orders made by the customer.
- Monetary: Total revenue generated by the customer.
The reference date (snapshot_date) is set to one day after the latest invoice date in the cleaned dataset.
4. Data transformation and scaling
The three RFM features are transformed using log1p and then standardized with StandardScaler. This prepares the data for clustering.
5. K-Means clustering
- The Elbow Method is used to inspect inertia for cluster counts from 2 to 10.
- Silhouette Scores are calculated for the same range.
- The number of clusters with the highest silhouette score is selected.
- K-Means is fitted using that selected cluster count.
6. DBSCAN clustering
- A 10-nearest-neighbour distance plot is generated for inspection.
- DBSCAN is applied with eps=0.8 and min_samples=10.
- The notebook reports the number of clusters and the percentage of customers labelled as noise (-1).
7. Visualisation
PCA is used to calculate two components and report the explained variance. t-SNE is also used to create a two-dimensional representation of the scaled customer data.

Scatter plots display the K-Means and DBSCAN cluster assignments using the t-SNE coordinates.
8. Customer profiling and personas
For each K-Means cluster, the notebook calculates customer count, average and median RFM values, and the percentage of customers in the cluster.

It then assigns a customer persona using the cluster's median RFM values:
- Champions
- At-Risk Loyal Customers
- Frequent Low-Spenders
- Recent High-Spenders
- Hibernating Customers
- Developing Customers
How to Run
Requirements
Python 3. Install the libraries with:
pip install pandas numpy matplotlib seaborn scikit-learn ucimlrepo
Run the notebook
1. Download or clone this project.
2. Open CaseStudy3.ipynb in Jupyter Notebook, JupyterLab, or Google Colab.
3. Run the cells from top to bottom.
4. Make sure internet access is available when fetching the UCI dataset.
Main Outputs
The notebook produces:
- Dataset preview, structure, and missing-value summary.
- Recency, Frequency, and Monetary distribution plots.
- K-Means Elbow Method plot.
- K-Means Silhouette Analysis plot.
- DBSCAN K-distance plot.
- K-Means and DBSCAN cluster counts.
- PCA explained-variance information.
- t-SNE visualisations of both clustering results.
- K-Means cluster profile table and customer persona labels.
